# Feature map

One file per user-facing feature. Each says how a user reaches it, how to drive it, and what
end state proves it. Never save during a drive (see ../SKILL.md, Seed).

- `global-search.md`: header Search button, full-screen search sheet
- `add-bill.md`: add bill page and the group Add bill dialog (amount inputs, Paid by, Paid in)
- `record-payment.md`: Person page Record payment dialog
- `app-shell.md`: header, bottom nav, offline banner, loading bar
